Cause
- A file in the project contains characters Netlify rejects in artifact filenames (commas, possibly other punctuation or excessively long name). The functions bundler attempted to include that file in the deployment and Netlify refused the filename, causing the build to fail.

Solution
1. Locate the offending file(s)
- From the repository root run (this finds filenames containing commas):
```bash
# show tracked files containing commas
git ls-files | grep ','
# search the working tree (including untracked files)
find . -name '*\,*' -print
# specifically check the functions directory
find netlify/functions -name '*\,*' -print
```

2. Remove or rename the offending file(s)
- If the file is an asset that doesn’t belong inside netlify/functions, move it to a public/static or assets folder (or external storage) and update any code that references it.
- If you need the file in the repo, rename it to remove commas and other unsafe characters (use hyphens or underscores). Example rename:
```bash
# example: rename a file that currently contains commas
git mv "netlify/functions/2,60,000rs_only_for_the_necklace_18kt_gold_hallmarked_certified_real_diamond_polkis_..." \
       "netlify/functions/260000rs_only_for_the_necklace_18kt_gold_hallmarked_certified_real_diamond_polkis_..."
git commit -m "Rename file to remove commas from filename"
git push
```
- If the filename is generated during build, change the generator to sanitize file names (strip commas and illegal chars, replace spaces with hyphens, limit length).

3. Re-run the build
- Push the change and trigger a deploy. Optionally test locally:
```bash
# test netlify build locally (if you have netlify-cli installed)
netlify build
```

Notes and best practices
- Do not store large binary assets inside netlify/functions — functions should contain code only. Move images/assets to public/ or to a CDN/S3.
- If you can’t find any comma-named file in netlify/functions, search the whole repo (step 1) — the bundler may be picking up files referenced by functions.
- After renaming, make sure any code that reads that filename is updated.
