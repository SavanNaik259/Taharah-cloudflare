Environment Variable Check (Server-side)

To verify Firebase Private Keys or other secrets on Cloudflare Pages:

  1. Go to your Cloudflare Dashboard.
  2. Navigate to Workers & Pages > [Your Project] > Settings > Variables.
  3. Ensure the variables are set for the Production environment.
  4. If you are using Cloudflare Functions (the functions/ folder), ensure you have redeployed after adding variables.
